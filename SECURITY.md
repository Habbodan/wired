# Security policy

Please don't report vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/Habbodan/wired/security/advisories/new) or email info@habbodan.com. Include the steps to reproduce it and the impact you expect. We'll reply within a few days and keep you updated until it's fixed.

Never include real Web API keys, session cookies or other people's data in a report.
